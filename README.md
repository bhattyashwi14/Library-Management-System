# Library Management System

A Java-based console application developed during **Semester 1** to simulate the core functionalities of a Library Management System.

The project was built to strengthen Object-Oriented Programming concepts by implementing real-world library operations such as member management, book management, borrowing, returning, and searching books through a menu-driven interface.

As one of my earliest Java projects, it helped me understand how theoretical OOP concepts can be applied to build practical software solutions.

---

## Features

### Member Functionalities

- View Profile
- Borrow Books
- Return Books
- Browse Academic Books
- Browse Non-Academic Books

---

### Librarian Functionalities

- Add Members
- Delete Members
- View Member Details
- Add Books
- Add Book Copies
- Remove Books
- Search Books

---

## Book Management

The system maintains:

- Book Title
- Author Name
- Available Copies

Users can:

- Search books
- Borrow books
- Return books
- Check availability

---

## Member Management

The system stores:

- Member Name
- Member ID
- Number of Borrowed Books

The application enforces borrowing limits and validates member operations to maintain library rules.
